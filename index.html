What is the CODM Public Test Build?

The CODM Public Test Build (also known as the CODM Test Server) is an early-access environment released by the developers. It allows players to experience upcoming game updates, new maps, weapons, and balance changes before they are launched in the official version.

Available Downloads

Access the newest official public test builds deployed by the developers. Please select the appropriate package file optimized for your mobile device specifications below:

  • iOS Build (Apple TestFlight)
    Designed for iPhone and iPad environments. Requires Apple's native TestFlight application. Note: Slot capacity is limited by developer project pools.
  • Android Build (32-Bit)
    Legacy deployment optimized for older mobile chipsets or budget hardware configurations.
  • Android Build (64-Bit)
    High-performance deployment package recommended for modern Android devices using up-to-date processors.

If you are uncertain about your processor configuration, the 64-bit build provides optimal compatibility and stability on newer flagship devices.

Step-by-Step Installation Guide

Follow these official procedures to set up the public test build on your device.

For Android Players

  1. Select either the 32-bit or 64-bit download link. The 64-bit version is engineered for superior performance on modern device hardware.
  2. The installation package file will automatically download to your system storage.
  3. Open your device's File Manager or Download Manager, tap the downloaded APK file, and proceed to install the Call of Duty: Mobile Test Build.

For iOS Players

  1. Tap the TestFlight download link to initiate the setup pathway through Apple's TestFlight platform.
  2. Download and install the official TestFlight application from the App Store if prompted.
  3. Once installed, return to this hub and click the TestFlight link once more to download and install the test build.

Account Setup & Lobby Access

For both platforms, select the Guest option to create your initial test account. After completing the brief introductory tutorial, you will gain full access to the standard test server lobby.
